- **A — סרגל עליון** (כהה, 56px): ימין: חזרה + כותרת + "נשמר". מרכז: לשוניות מצב (במקום ה-Ribbon העמוס של Sibelius במחשב, כמו ב-Sibelius למובייל — סרגל דק). שמאל: **↶ Undo**, ↷ Redo, ▶ השמעה, ⋮ (ייצוא, הגדרות דף, הגדרות).
- **B — Ribbon** (בהיר, 52px): תוכן משתנה לפי לשונית. "הזנת תווים": chips מפתח/סולם/משקל/טמפו/זום. "סימנים": articulations, דינמיקה. "תיבות": הוספה/מחיקה, קווי תיבה, חזרות, שינוי משקל/סולם מכאן. "טקסט": כותרת, הערה, סימני אקורד (שלב 2). "השמעה": טמפו, ×0.5/×0.75, מטרונום, loop.
- **C — דף**: נייר לבן עם צל עדין על רקע אפור, גלילה אנכית, zoom בצביטה 60–200%. cursor הזנה סגול.
- **D — context bar**: מופיע מעל בחירה (תו או טווח), בתוך המסך תמיד.
- **E — Keypad צף**: ברירת מחדל בפינה התחתונה שמאלית (בצד הקצה של RTL), ניתן לגרירה מכל קצה; המיקום נשמר בנפרד ל-landscape ול-portrait (כמו Sibelius). כפתור ✕ מסתיר; כפתור סגול צף מחזיר.
- **F/G — פסנתר**: ידית ▾ פותחת/סוגרת; טווח ברירת מחדל C1–C4 לבס, נגלל באצבע; בסול C4–C6.
- portrait: ה-Keypad נצמד לתחתית ברוחב מלא (גובה ~230px), הפסנתר מעליו מתקפל.

## 6. מודל האינטראקציה
### 6.1 עקרונות (מבוסס על הדפוס של Sibelius למובייל)
- **מגע על הדף = בחירה ומיקום cursor.** הזנה מדויקת נעשית דרך Keypad/פסנתר, כדי שהאצבע לא תסתיר את התו.
- **הקשה ישירה על החמשה** נשארת כקיצור (פול ביקש): במצב "הקשה" (chip "קלט") הקשה על קו/רווח בתיבה מוסיפה תו במשך הפעיל. ניתן לכבות.
- כל הדרכים עובדות בכל רגע, בלי מצבים נסתרים; המשך הפעיל תמיד מסומן בסגול ב-Keypad.
- הערה משפטית: לא מעתיקים אייקונים, גרפיקה, קוד או שמות מסחריים של Avid/Sibelius. ממחזרים רק את דפוס ה-UX הכללי, ומעצבים אייקונים משלנו (SVG). Avid מציינים שיטות הזנה ב"patent pending"; היקף הפטנט **לא אומת**. לפני פרסום רחב, לבדוק, או להשאיר את ה"גרירה על ה-Keypad" כאופציה שאפשר לכבות.

### 6.2 זרימה: הכנסת תו
1. הקשה על תיבה → התיבה נבחרת וה-cursor (קו סגול) עומד בתחילתה. או הקשה אחרי התו האחרון → cursor בסוף.
2. אחת מהדרכים:
   - **Keypad**: לחיצה והחזקה על משך → ghost בגובה האחרון (ברירת מחדל: הקו האמצעי D3 בפה) → גרירה למעלה/מטה = גובה דיאטוני (צעד כל 14px), ימינה = ♯, שמאלה = ♭ → שחרור = התו נכנס. הקשה קצרה על משך = בחירת משך בלבד.
   - **פסנתר**: מקש = תו בגובה המדויק, במשך הפעיל, ב-cursor (מקש שחור = ♯/♭ לפי הסולם).
   - **הקשה על החמשה**: snap לקו/רווח, עם ghost ותווית לפני שחרור.
3. התו מודפס (≤100ms), נשמע preview (אם ההשמעה פעילה), ה-cursor מתקדם.
4. הפסקה: משך פעיל + 𝄽, או החלקה ימינה/שמאלה על 𝄽 לבחירת משך ההפסקה.

### 6.3 זרימה: שינוי גובה
- בחירת תו (הקשה עליו) → context bar: ▲/▼ צעד דיאטוני (לחיצה ארוכה = חזרה), ♯/♭.
- או גרירה על כפתור ↕ ב-Keypad (למעלה/מטה גובה, ימינה/שמאלה ♯/♭).
- או מקש בפסנתר כשתו נבחר = **החלפת גובה** (לא הוספה).
- כל שינוי: תווית הגובה מתעדכנת, preview נשמע.

### 6.4 זרימה: שינוי משך
- תו נבחר + הקשה על משך ב-Keypad או ב-context bar → המשך משתנה; normalize מפצל/ממלא הפסקות.
- נקודה: · (1 → 2 → 0). tie: ⁀ לתו הבא באותו גובה.

### 6.5 זרימה: מחיקה
- תו/טווח נבחר → 🗑 ב-context bar, או "מחק" ב-Keypad, או Backspace.
- באמצע תיבה התו הופך להפסקה; בסוף הזרם הוא נמחק. Toast "נמחק · בטל" למשך 4 שניות.
- **Undo** תמיד גלוי בסרגל העליון ובשורה העליונה של ה-Keypad.

### 6.6 זרימה: בחירת טווח
- לחיצה ארוכה (350ms) וגרירה = lasso; או הקשה על תו ואז Shift-like: הקשה ארוכה על תו שני מרחיבה.
- הקשה על התיבה = בחירת תיבה; הקשה כפולה = כל השורה.
- הטווח מסומן ברקע `--select-soft`; context bar: מחיקה, שינוי משך לכולם, ▲▼ טרנספוזיציה, העתק/הדבק.
- הקשה על שטח ריק / Esc = ביטול בחירה.

### 6.7 מחוות ועט
- צביטה = zoom; גרירה בשתי אצבעות = גלילה; הקשה בשתי אצבעות = undo, שלוש = redo.
- **עט — שלב מאוחר** (§9 שלב F):
  `pointerType:"pen"`
  עט על הדף = הקשה מדויקת (ללא ghost offset), palm rejection; זיהוי כתב יד = מחוץ לתחום.
- מקלדת חיצונית: כמו v2 §6.3, ובנוסף מקשי מספרים בסגנון Keypad (1–6 משכים).

## 7. קריטריוני קבלה
1. עבודה ב-branch `v3-sibelius-style`, PR עם קישור preview וצילומי מסך; לא ממוזג בלי אישור מפורש של פול.
2. המסך הראשי ב-landscape 1280×800 תואם ל-`v3-mockup.png` (אזורים A–G, צבעים מ-§4), בלי שגיאות console.
3. ממשק עברי RTL מלא; אזור התווים LTR; אין טקסט באנגלית בממשק חוץ משמות תווים (A2) ומונחים כמו MusicXML.
4. כל כפתור ב-Keypad ≥ 56px, בסרגלים ≥ 44px; Keypad נגרר, נסתר ומוחזר, והמיקום נשמר לכל כיוון מסך.
5. דף חדש: מפתח פה, 4/4, C מז'ור, ♩=100; אפשר לבחור סול/grand; מפתח נשמר לכל דף.
6. הכנסת תו דרך Keypad (החזקה+גרירה) מגיעה לכל גובה E1–C4 בפה, עם ghost ותווית, ו-♯/♭ בהחלקה אופקית.
7. הכנסת תו דרך פסנתר נותנת בדיוק את הגובה של המקש (כולל מקשים שחורים לפי הסולם).
8. הקשה על החמשה (כשמופעלת) מכניסה תו בגובה הנכון לפי מיפוי v2 §7; ≤100ms מהקשה לתו.
9. בחירת תו מציגה context bar תוך ≤100ms; ▲▼ ♯♭ משנים גובה; משך ונקודה משנים משך; normalize תקין.
10. מחיקה (context bar / Keypad / Backspace) עובדת לתו ולטווח, עם toast ו-undo.
11. Undo/Redo גלויים תמיד, ≥200 צעדים, ≤30ms, כולל שינויי סולם/משקל/מפתח.
