# מחברת בס

מחברת דיגיטלית לטאבלט אנדרואיד: רושמים רעיון מוזיקלי מהר, בעט על הדף או בהקשה של תווים על חמשה, וכל רעיון נשמר כדף במכשיר. בלי חשבון, בלי שרת, ובלי רשת אחרי הטעינה הראשונה.

הממשק בעברית מימין לשמאל. אזור התווים עצמו נכתב משמאל לימין, כמו תווים.

## התקנה בטאבלט אנדרואיד

1. פותחים את האתר בכרום.
2. לוחצים על ⋮ בתפריט הדפדפן.
3. בוחרים **התקן אפליקציה** או **הוסף למסך הבית**.
4. בפתיחה הבאה האפליקציה עולה גם בלי רשת. כדאי לפתוח אותה פעם אחת עם רשת, כדי שהקבצים יישמרו במכשיר.

## שני מצבים

בסרגל הצד מתג גדול: **✎ עט** ו-**♪ הקשה**. המעבר מיידי, ושתי השכבות נשארות על אותו דף.

- **עט** — קו חלק עם עובי לפי לחץ. ארבעה צבעים, שלושה עוביים, מרקר ומחק שמוחק קו שלם. כשזוהה עט, נגיעת אצבע לא מציירת אלא גוללת. אפשר לכבות את זה בהגדרות («עט בלבד מצייר»).
- **הקשה** — בוחרים משך, נקודה, סימן היקר או הפסקה, ונוגעים בחמשה. הגובה נקבע לפי הקו או הרווח הקרוב. תו שלא נכנס בתיבה עובר לתיבה הבאה.

דף חדש נפתח במפתח פה, במשקל 4/4, בסולם דו, עם שש שורות. אפשר לשנות מפתח לדף כולו או לשורה אחת: פה, סול, או מערכת כפולה (סול מעל פה, עם סוגריים). החלפת מפתח לא משנה את גובה הצליל של תווים שכבר נכתבו.

| גובה במקלדת | A–G |

| נקודה | . |

שמירה אוטומטית אחרי כל שינוי. אין כפתור שמירה.

## גיבוי ושחזור

הדפים נשמרים רק בדפדפן של המכשיר הזה. מחיקת נתוני האתר מוחקת את המחברת.

בהגדרות:

- **גיבוי לקובץ JSON** מוריד `bass-notebook-backup-YYYY-MM-DD.json`.
- **שחזור מקובץ** מציג כמה דפים נמצאו. **מיזוג** שומר את הגרסה עם תאריך העדכון החדש יותר. **החלפה** דורשת אישור נוסף ומחליפה את כל הדפים.
- קובץ פגום נדחה, והנתונים במכשיר לא משתנים.

אפשר גם לייצא את הדף הפתוח כ-PNG (תווים, כתב יד וכותרת, על רקע בהיר).

## הרצה מקומית

אין שלב בנייה. מתיקיית הפרויקט:

```bash
python3 tools/serve.py 4173
```

או:

```bash
npx serve
```

פותחים את `http://127.0.0.1:4173/`.

## בדיקות

צריך Node.js 18 ומעלה.

```bash
npm install
npx playwright install chromium
npm test
```

הבדיקות רצות בשלושה מצבי תצוגה: דסקטופ, טאבלט לרוחב (Galaxy Tab S4) וטאבלט לאורך.
